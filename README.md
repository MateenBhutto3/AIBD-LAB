# AIBD Lab website

Bilingual (English / 简体中文) static website for the Artificial Intelligence and Big Data Laboratory, School of Software, Shenyang University of Technology. Plain HTML/CSS/vanilla JS generated by a dependency-free Node script.

## Edit content
All content lives in `/data`: `site.json` (lab info + all UI strings), `members.json`, `publications.json`, `projects.json`, `awards.json`, `research.json`, `news.json`. Every text field has `en` and `zh`. Photos go in `src/assets/img/people/` (JPG + WebP) and are referenced by `photo.src`.

## Build
`npm run build` → `dist/`. Optional env: `SITE_URL` (for canonical/sitemap) and `BASE_PATH` (e.g. `/repo-name/` for GitHub Pages; default `/`).

## Deploy
- **Netlify:** connect the repo; `netlify.toml` sets `npm run build` and publish `dist`.
- **GitHub Pages:** build with `BASE_PATH=/repo-name/` and publish `dist` (a workflow file is still to be added — see PLAN.md). `.nojekyll` and `404.html` are generated.
